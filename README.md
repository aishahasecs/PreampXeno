# PreampXeno

Highly scalable, load-balanced PreampXeno Server architecture enables real-time audio processing through auto-scaling PreampXeno Engine.

PreampXeno is built to be simple and practical, focusing on doing one thing well.

**Why PreampXeno?**

- Highly scalable, load-balanced PreampXeno Server
- architecture enables real-time audio processing
- through auto-scaling PreampXeno Engine

## Technology Stack

- rust

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PreampXeno.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

PreampXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
